# kidnamedvasu — Video Editing Portfolio

> Professional short-form video editor crafting scroll-stopping content for Instagram Reels and YouTube Shorts.

## 🚀 Live Demo
Visit the live portfolio: [https://kidnamedvasu.github.io](https://kidnamedvasu.github.io)

## 🛠️ Features
- **Cinematic Dark & Sky-Blue Aesthetic**: Modern Y2K minimal editorial theme.
- **Interactive 3D Cube**: Drag-to-rotate 3D cube showcasing creative editing categories.
- **NLE Editing Timeline**: Real-time animated playhead syncing to viewer scroll.
- **Horizontal Looping Reel Showcase**: Carousel of client vertical reels with focused center scaling.
- **Custom Interactive Cursors**: Contextual "WATCH" cursor on video cards.
- **Mobile Responsive**: Smooth touch drag and navigation across all devices.
